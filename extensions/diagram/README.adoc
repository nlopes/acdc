= Diagram extensions for acdc

== WaveDrom

Applications can register the `wavedrom` style for listing blocks (`----`) and literal blocks (`....`).
Supply the path to a trusted `wavedrom-cli` executable and the directory containing the converted document.
The extension runs the executable only for an explicitly registered style in `SafeMode::Unsafe`.
Use this mode for trusted input. The acdc CLI accepts `--extension diagram --wavedrom-cli PATH` when built with the optional `diagram` feature.
For TikZ, supply `--lualatex PATH` and optionally `--pdf2svg PATH`.
The link:../../acdc-cli/README.adoc[CLI guide] describes asset locations for files, streams, and embedded images.

[source,rust]
----
let mut builder = acdc_parser::extensions::Registry::builder();
builder.register_block_style(acdc_diagram::wavedrom(&tool, &output_dir)?)?;
let options = acdc_parser::Options::builder()
    .with_safe_mode(acdc_parser::SafeMode::Unsafe)
    .build()?;
let parsed = builder.build().parse(source, &options)?.finish()?;
----

[source,asciidoc]
----
[wavedrom, ,svg]
....
{signal: [{name: 'clock', wave: 'p...'}]}
....
----

Diagram renderers receive the preprocessed body verbatim by default.
Use `subs=attributes` to expand references such as `{signal-label}` with the value in effect at the block.
With expansion enabled, `\{signal-label}` passes a literal `{signal-label}` to the tool. Unknown references stay in the source.
Only the attribute step of a `subs` setting affects diagram source. Formatting, escaping, and callout processing are left to the renderer.

The first positional argument names the output, e.g. `[wavedrom,clock,svg]` produces `clock.svg`.
Use a relative target such as `boards/rev-a/clock_signal` to write `boards/rev-a/clock_signal.svg` under the current image directory.
Each slash-separated segment accepts ASCII letters, digits, hyphens, and underscores.
Diagram blocks use the final segment as the default alternative text, with hyphens and underscores displayed as spaces.
An unnamed diagram defaults to `Diagram`. Set `alt="Clock and reset"` to supply a label or `alt=""` for a decorative image.
An empty target uses a SHA-256 digest of the renderer input, including the selected layout for Graphviz. Named `target=` and `format=` take precedence.
The image is an ordinary acdc block. Its file is written under the output directory using the `imagesdir` in effect at the block.
Set `:imagesoutdir: staging` to write diagrams under `staging` while keeping `imagesdir` in published links.
Embedding reads the staged file directly. Unset the attribute with `:imagesoutdir!:` to resume writing under `imagesdir`.
The CLI resolves `imagesoutdir` from its working directory. Library callers can set its base with `OutputDirectories::with_imagesoutdir_base`.
Directories used for writing must be relative and cannot contain symlinks, parent traversal, URI escapes, query strings, or fragments.
In HTML, the default `static` SVG type produces an `<img>`. Set `:diagram-svg-type: inline` to embed SVG markup or `:diagram-svg-type: interactive` to use an `<object>`.
A renderer-specific attribute such as `graphviz-svg-type` overrides the shared setting. Each block can override it with `svg-type=static`, `inline`, or `interactive`.
Explicit `opts=inline` or `opts=interactive` takes precedence over `svg-type`. If both options are present, inline wins.
For HTML, SVG diagrams supply default image dimensions from their absolute width and height, or from the `viewBox` when either dimension is unavailable.
PNG diagrams use the pixel width and height of the generated raster.
Use `scale=0.5` to halve those defaults. Explicit `width` and `height` each override the corresponding default.
acdc uses Asciidoctor Diagram’s factor of 1.33 for TeX points and truncates fractional pixels after scaling.
For other physical units acdc uses 96 pixels per inch. A `viewBox` offset does not change its width or height.
Use `[wavedrom,clock,png]` to generate `clock.png`. WaveDrom defaults to SVG.
Set `:diagram-format: svg` to select a common format for the registered renderers.
A block's positional or named format overrides the renderer-specific attribute (such as `graphviz-format`), which in turn overrides `diagram-format`.
Each block uses the document attributes in effect at its location. Unsetting a renderer-specific format restores the shared default.
An empty format reports an unsupported format. Use `:diagram-format!:` to restore automatic selection.
If a renderer fails to generate an image, the default `diagram-on-error=log` reports a warning at the block and continues conversion.
The output contains a listing with the error and the diagram source, including any requested attribute expansion. A previous image file is preserved.
Set `:diagram-on-error: abort` to stop at the first failure. The block's `on-error` attribute overrides the renderer-specific attribute (such as `graphviz-on-error`), which overrides `diagram-on-error` in effect at the block.
Restricted safe modes still stop before running any tool.
Each render uses a temporary directory under the image output directory. On Unix, acdc creates it with owner-only access. On Windows, it inherits the output directory’s access controls.
After success or a renderer error, acdc removes the temporary directory.

== TikZ

Register the `tikz` style for listing and literal blocks with the application's LuaLaTeX executable, an optional pdf2svg executable, and the converted document's output directory.

[source,rust]
----
builder.register_block_style(acdc_diagram::tikz(&lualatex, Some(&pdf2svg), &output_dir)?)?;
----

Use `[tikz,figure,svg,preamble=true,command=lualatex]` on a listing or literal block to produce `figure.svg`.
Put the TeX preamble before a line containing exactly `~~~~`, then the picture after it.
With no separator the complete body becomes picture content.
Use `pdf` for native one-page PDF output. With no explicit format, HTML backends prefer SVG when pdf2svg is configured. The PDF backend defaults to SVG and requires pdf2svg to embed the diagram. Other configurations default to PDF.

LuaLaTeX runs only in unsafe mode on trusted documents, with shell escape disabled.
The block's `command` and document's `tikz-command` can select only `lualatex`.
Fonts and packages must be discoverable by the caller's TeX installation.
The existing target naming, source-position `imagesdir`, atomic publication, and located error behavior also apply to TikZ.

== Graphviz

Register `acdc_diagram::graphviz(&dot, &output_dir)` or pass `--extension diagram --graphviz-dot /usr/bin/dot` in the CLI.
Use `[graphviz,flow,svg]` on a listing or literal block containing DOT source. Graphviz defaults to PNG and also supports PDF.
Set `:graphviz-layout: dot` for subsequent blocks or select an installed layout per block with `layout=neato`.
Graphviz reads the diagram on standard input. Relative resources resolve from the caller's source directory for file conversion.
The CLI also registers `graphviz::graphs/chart.dot[svg,alt="*Graph*"]`. In a library, register `acdc_diagram::graphviz_file(&dot, &output_dir)?` with the registry's `register` method.
The macro reads DOT through the parser's include loader. It accepts UTF-8 and Unicode files with a byte order mark. The target resolves like a local include and its bytes count toward the same document limit. Graphviz resolves resources inside the graph relative to the DOT file. The example writes `chart.svg`. Without an explicit `target` or `alt`, the alternative text is `Diagram`. The file stem follows the same output-name rules as a diagram block. Use `target=other-name` to override it.
Only the caller selects the executable. Rendering requires unsafe mode.

== Message sequence charts

Pass `--extension diagram --mscgen /usr/bin/mscgen` to render a listing or literal block styled `[msc]`, or load a local file with `msc::charts/exchange.msc[svg]`.
In a library, register the block style returned by `acdc_diagram::msc` and the block macro returned by `acdc_diagram::msc_file`.
Both forms default to PNG. Select SVG with the positional format, `format=svg`, or `:msc-format: svg`.
Native mscgen uses the `font` argument for PNG output. Set a document default with `:msc-font: DejaVu Sans`.
The macro reads its source through the parser's include loader. Rendering requires unsafe mode and a caller-selected executable.

== Verification

With mscgen 0.20, acdc and Asciidoctor Diagram 3.2.1 rendered the same two-entity request and response chart as a 600 × 102 PNG block and a 600 × 78 SVG file macro. The image targets, alternative text, and numbered figure captions matched.

Graphviz 14.1.2 rendered the same DOT graph with the `dot` layout through acdc and Asciidoctor Diagram 3.2.1. The HTML image paths, alternative text, and dimensions matched for PNG, SVG, and PDF.
For `graphviz::graphs/chart.dot[svg,alt="*Graph*"]`, both CLIs linked `chart.svg`, preserved the literal asterisks in the alternative text, and numbered the titled image as a figure.

The WaveDrom adapter uses the file-to-file protocol from https://github.com/nlopes/acdc/pull/451[acdc-diagram].
The acceptance fixture reproduces the https://github.com/riscv/riscv-high-assurance-cryptography/blob/6b82dbaf0096747c8acee1749a1e1c188474f478/src/ace-ISA-unpriv.adoc#L1184-L1193[RISC-V ACE register diagram for ace.load], licensed under https://creativecommons.org/licenses/by/4.0/[CC BY 4.0].
It was verified with `wavedrom-cli` 3.2.0. To run the real-renderer test:

[source,console]
----
ACDC_WAVEDROM_CLI=/absolute/path/to/wavedrom-cli cargo nextest run -p acdc-diagram --all-features --run-ignored only -E 'test(=ace_register_diagram_with_real_wavedrom_cli)'
----

The https://github.com/riscv/riscv-high-assurance-cryptography/blob/6b82dbaf0096747c8acee1749a1e1c188474f478/src/ace-ISA-unpriv.adoc#L513-L587[ACE state diagram fixture] is extracted from a comment in the same CC BY 4.0 source.
Install the TeX packages for standalone, TikZ, and fontspec and make the four https://github.com/riscv/docs-resources/tree/2aef34ec803cf3475376172bac78a35d5801cb21/fonts[Petrona Light and Medium upright and italic font files] available to LuaLaTeX.
The reference comparison used LuaHBTeX 1.24.0, pdf2svg 0.2.4, and Asciidoctor Diagram 3.2.1 configured to run the same LuaLaTeX engine with shell escape disabled.
To verify both formats with the real tools:

[source,console]
----
ACDC_LUALATEX=/absolute/path/to/lualatex ACDC_PDF2SVG=/absolute/path/to/pdf2svg cargo nextest run -p acdc-diagram --all-features --run-ignored only -E 'test(=ace_state_diagram_with_real_lualatex)'
----

=== PDF conversion

The November 2026 comparison used acdc CLI 0.3.0 and Asciidoctor PDF 2.3.19 with Asciidoctor 2.0.26 and Asciidoctor Diagram 3.2.1.
Both backends rendered the ACE register and state machine from the fixtures above in a single document, using wavedrom-cli 3.2.0, LuaHBTeX 1.24.0 with shell escape disabled, and pdf2svg 0.2.4.

With SVG for both figures, each PDF had one page. The register labels (including `ace.load`, `context`, and `immed12`) were selectable text.
Both PDFs retained the state machine as vector paths and numbered the captions _Figure 1. ACE register_ and _Figure 2. ACE state machine_.
Switching just the register to PNG embedded an 800 × 84 image with an alpha mask in each PDF. The page layouts gave the raster different displayed widths (127 ppi in acdc and 115 ppi in Asciidoctor PDF).

= Diagram extensions for acdc

== WaveDrom

Applications can register the `wavedrom` style for listing blocks (`----`) and literal blocks (`....`).
Supply the path to a trusted `wavedrom-cli` executable and the directory containing the converted document.
The extension runs the executable only for an explicitly registered style in `SafeMode::Unsafe`.
Use this mode for trusted input. The acdc CLI accepts `--extension diagram --wavedrom-cli PATH` when built with the optional `diagram` feature.
For TikZ, supply `--lualatex PATH` and optionally `--pdf2svg PATH`.
The link:../../acdc-cli/README.adoc[CLI guide] describes asset locations for files, streams, and embedded images.

[source,rust]
----
let mut builder = acdc_parser::extensions::Registry::builder();
builder.register_block_style(acdc_diagram::wavedrom(&tool, &output_dir)?)?;
let options = acdc_parser::Options::builder()
    .with_safe_mode(acdc_parser::SafeMode::Unsafe)
    .build()?;
let parsed = builder.build().parse(source, &options)?.finish()?;
----

[source,asciidoc]
----
[wavedrom, ,svg]
....
{signal: [{name: 'clock', wave: 'p...'}]}
....
----

WaveDrom and TikZ receive the preprocessed body verbatim by default.
Use `subs=attributes` to expand references such as `{signal-label}` with the value in effect at the block.
With expansion enabled, `\{signal-label}` passes a literal `{signal-label}` to the tool. Unknown references stay in the source.
Only the attribute step of a `subs` setting affects diagram source. Formatting, escaping, and callout processing are left to the renderer.

The first positional argument names the output, e.g. `[wavedrom,clock,svg]` produces `clock.svg`.
Target names accept ASCII letters, digits, hyphens, and underscores.
An empty target uses a SHA-256 digest of the source sent to the renderer. Named `target=` and `format=` take precedence.
The image is an ordinary acdc block. Its file is written under the output directory using the `imagesdir` in effect at the block.
Use local relative image directories without URI escapes, query strings, or fragments. Symlinks in the directory path, parent traversal, and `imagesoutdir` overrides are rejected.
Use `[wavedrom,clock,png]` to generate `clock.png`. SVG is the default.
The block’s format takes precedence over the `wavedrom-format` document attribute in effect at the block.
If WaveDrom or TikZ fails to generate an image, the default `diagram-on-error=log` reports a warning at the block and continues conversion.
The output contains a listing with the error and the diagram source, including any requested attribute expansion. A previous image file is preserved.
Set `:diagram-on-error: abort` to stop at the first failure. The block's `on-error` attribute overrides `wavedrom-on-error` or `tikz-on-error`, which override `diagram-on-error` in effect at the block.
Restricted safe modes still stop before running any tool.

== TikZ

Register the `tikz` style for listing and literal blocks with the application's LuaLaTeX executable, an optional pdf2svg executable, and the converted document's output directory.

[source,rust]
----
builder.register_block_style(acdc_diagram::tikz(&lualatex, Some(&pdf2svg), &output_dir)?)?;
----

Use `[tikz,figure,svg,preamble=true,command=lualatex]` on a listing or literal block to produce `figure.svg`.
Put the TeX preamble before a line containing exactly `~~~~`, then the picture after it.
With no separator the complete body becomes picture content.
Use `pdf` for native one-page PDF output. With no explicit format, HTML backends prefer SVG when pdf2svg is configured. The PDF backend defaults to SVG and requires pdf2svg to embed the diagram. Other configurations default to PDF.

LuaLaTeX runs only in unsafe mode on trusted documents, with shell escape disabled.
The block's `command` and document's `tikz-command` can select only `lualatex`.
Fonts and packages must be discoverable by the caller's TeX installation.
The existing target naming, source-position `imagesdir`, atomic publication, and located error behavior also apply to TikZ.

== Verification

The adapter uses the file-to-file protocol from https://github.com/nlopes/acdc/pull/451[acdc-diagram].
The acceptance fixture reproduces the https://github.com/riscv/riscv-high-assurance-cryptography/blob/6b82dbaf0096747c8acee1749a1e1c188474f478/src/ace-ISA-unpriv.adoc#L1184-L1193[RISC-V ACE register diagram for ace.load], licensed under https://creativecommons.org/licenses/by/4.0/[CC BY 4.0].
It was verified with `wavedrom-cli` 3.2.0. To run the real-renderer test:

[source,console]
----
ACDC_WAVEDROM_CLI=/absolute/path/to/wavedrom-cli cargo nextest run -p acdc-diagram --all-features --run-ignored only -E 'test(=ace_register_diagram_with_real_wavedrom_cli)'
----

The https://github.com/riscv/riscv-high-assurance-cryptography/blob/6b82dbaf0096747c8acee1749a1e1c188474f478/src/ace-ISA-unpriv.adoc#L513-L587[ACE state diagram fixture] is extracted from a comment in the same CC BY 4.0 source.
Install the TeX packages for standalone, TikZ, and fontspec and make the four https://github.com/riscv/docs-resources/tree/2aef34ec803cf3475376172bac78a35d5801cb21/fonts[Petrona Light and Medium upright and italic font files] available to LuaLaTeX.
The reference comparison used LuaHBTeX 1.24.0, pdf2svg 0.2.4, and Asciidoctor Diagram 3.2.1 configured to run the same LuaLaTeX engine with shell escape disabled.
To verify both formats with the real tools:

[source,console]
----
ACDC_LUALATEX=/absolute/path/to/lualatex ACDC_PDF2SVG=/absolute/path/to/pdf2svg cargo nextest run -p acdc-diagram --all-features --run-ignored only -E 'test(=ace_state_diagram_with_real_lualatex)'
----

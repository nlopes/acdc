= Native lists extension for acdc

`acdc-extensions-lists` implements `list-of::<element>[]` through the native
extension API. Register `acdc_extensions_lists::registry()?` with the parser or
as `lists` in converter core's `ExtensionCatalog`, then attach the selected
extensions to a configured `Pipeline`. Each parse gets its own processor state.
The CLI selection is not available yet.

[source,asciidoc]
----
list-of::image[]

.A diagram
[#diagram]
image::diagram.svg[]
----

The generated paragraph contains one linked line per titled or captioned target,
with explicit hard breaks. Captioned entries link their caption and put the title
after it. Other entries link their title. All backends render ordinary nodes.

Supported element names are `image`, `table`, `listing`, `literal`, `example`,
`quote`, `verse`, `sidebar`, `open`, `pass`, `stem`, `audio`, `video`, `admonition`,
`paragraph`, `section`, `olist`, `ulist`, `dlist`, and `colist`. Selection includes
nested containers and AsciiDoc table cells, and follows semantic block styles.
Requests may precede their targets. Untitled, uncaptioned targets are omitted.

Requests run in source order and capture their own membership and title context.
Later processors do not refresh those snapshots. The host preserves authored IDs,
assigns collision-safe deterministic IDs, reuses them for repeated requests, and
follows surviving targets if their IDs change. Final caption numbers come from
the host. Empty lists are removed without removing their containing section.
Unknown names return a located warning and retain the accepted `list-of` call
as literal text, including its arguments, quotes, and unexpanded target.

== Reference and deliberate differences

The reference is
https://github.com/Alwinator/asciidoctor-lists/blob/cd926c536bb0fd36985e1f7bff125e9b59fdbdb0/lib/asciidoctor-lists/extensions.rb[asciidoctor-lists at cd926c5],
characterized with Asciidoctor 2.0.26. The native extension uses deterministic IDs
instead of UUIDs. Titles retain ordinary parsed formatting and their original
attribute context. The Ruby default copies rendered title strings into newly
parsed AsciiDoc, which can expose escaped HTML tags. The native extension renders
the title once. A title with an explicitly empty caption appears once as a link;
the reference can duplicate it. Generated paragraphs retain authored block
metadata such as titles, IDs, and roles; the reference drops that metadata.

`enhanced_rendering`, `hide_empty_section`, and nonempty positional options are
rejected until their behavior is implemented. They are never silently ignored.

The link:./examples/render.rs[library example] renders a source file through the
shared HTML pipeline:

[source,console]
----
cargo run -p acdc-extensions-lists --example render -- document.adoc
----

New HTML expectations for this crate can be generated by exact source stem:

[source,console]
----
cargo run -p acdc-extensions-lists --example generate_fixtures --all-features -- default nested
----

Review every generated file. Existing expectations require approval before
regeneration, as elsewhere in the repository.

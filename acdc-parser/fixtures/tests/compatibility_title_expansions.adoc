:inner: _Nested_
:outer: \{inner}

Single quoted.

[title="{word}"]
Double quoted.

[title={word}]
Unquoted.

.{word}

[title='{outer}']
Nested reference.

[title='\{word}']
Escaped reference.

[title='++{word}++']
Protected after list expansion.

[title='pass:q[{word}]']
Formatting passthrough.

[title='Before {word} after']
Adjacent authored text.

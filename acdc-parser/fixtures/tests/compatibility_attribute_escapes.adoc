= Attribute Escapes
:who: café

[data="\{who}",role=one]
One backslash protects a reference.

[data="\\{who}",role=two]
Two backslashes select the mode's reference rule.

[data="\\\{who}",role=three]
Three backslashes preserve an escaped reference.

[data="\\\\{who}",role=four]
Four backslashes select the mode's reference rule.

[data="α\"β",role=quoted]
The matching quote is escaped.

[data="α\\\"β",role=odd]
An odd backslash run precedes an interior quote.

[data="α\\",role=even]
An even backslash run can precede a closing quote in Draft.

[data="C:\path\file",other=\{not a reference}]
Backslashes before ordinary text stay literal.

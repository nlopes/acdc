= Anchor with Spaces Test

Double-bracket anchor syntax with spaces stays literal. A shorthand-looking
value with spaces is a block style, not an ID.

[[my section id]]
== Section with Space in Anchor

The invalid double-bracket anchor above stays literal.

[#another space id]
== Section with Space in Shorthand

The shorthand-looking value above is a style, not an ID.

[[valid-id]]
== Valid ID Section

This section has a valid ID without spaces.

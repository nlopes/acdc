= Attribute Whitespace

[ source,role=leading]
Leading whitespace keeps this line in the paragraph.

[source,role=trailing ]
printf 'café'

image:diagram.svg[ café, width=25 ]

[data=" inner spaces ",role=quoted]
Quoted inner spaces stay in the value.

[role=first, data = value, other=second]
Spaces around entry separators are allowed.

printf 'expanded leading space'

[source{sp}]

### Added

- Initial Typst-backed PDF converter with broad support for AsciiDoc document
  structure, blocks, inlines, navigation, lists, tables, images, source code,
  indexes, and books. It includes PDF themes, page chrome, document metadata,
  trusted fonts, safe asset loading, strict asset checks, and optional Typst
  output for diagnostics.

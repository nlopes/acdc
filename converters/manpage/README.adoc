= `acdc-converters-manpage`

Manpage converter for `AsciiDoc` documents. Generates native roff/troff output suitable for the `man` command.

== Usage

[source,console]
....
acdc convert --backend manpage mycommand.adoc
....

This generates `mycommand.1` (or another extension based on the manual section) in the same directory as the source file.

== Output Format

Generates roff/troff format compatible with:

- GNU groff
- mandoc (OpenBSD)
- Traditional Unix nroff/troff

=== Roff Macros Used

- `.TH` - Title header with name, section, date, source, manual
- `.SH` - Section headings (NAME, SYNOPSIS, DESCRIPTION, etc.)
- `.SS` - Subsection headings
- `.PP` - Paragraph breaks
- `.IP`, `.TP` - Indented and tagged paragraphs for lists
- `.EX`/`.EE` - Example blocks (literal/listing content)
- `.TS`/`.TE` - Table start/end (tbl preprocessor)
- `\fB`, `\fI`, `\fR`, `\f(CR`, `\fP` - Bold, italic, roman, monospace, previous font

== Viewing Output

View the generated manpage:

[source,console]
....
man ./mycommand.1
....

Or with groff directly:

[source,console]
....
groff -man -Tascii mycommand.1 | less
....

=== macOS and tables

macOS ships with `mandoc` which has limited support for the `tbl` preprocessor.
Manpages that contain tables will show a warning:

....
This manpage is not compatible with mandoc(1) and might display incorrectly.
....

To render tables correctly, install GNU groff and use the `-t` flag to enable `tbl` processing:

[source,console]
....
brew install groff
groff -t -man mycommand.1 -T utf8 | less
....

== Technical Details

The manpage converter:

- Escapes special roff characters in prose, UI labels, STEM fallback text, and
  link and media arguments. Explicit passthrough blocks remain unescaped so
  they can contain backend-native roff.
  Keep raw font changes and their text within the same passthrough; parsed
  formatting restores its enclosing AsciiDoc font, not arbitrary raw roff state.
- Disables hyphenation (`.nh`) for consistent formatting
- Uses left-alignment only (`.ad l`) as is standard for manpages
- Includes the tbl preprocessor directive (`'\" t`) when tables are present
- Preserves inline formatting (bold, italic, monospace) using roff font escapes
- Preserves repeated spaces and tabs in prose and inline formatting, matching
  Asciidoctor. Indentation around wrapped source lines is removed so it does not
  introduce a new roff line or indent.
- Preserves verse line breaks and indentation while rendering normal inline
  formatting, typography, links, footnotes and index terms. Explicit `subs=`
  and inline passthroughs retain their usual control over substitutions.
- Renders quote and verse paragraph titles above their bodies, including inside
  AsciiDoc table cells. Titles use normal substitutions even when the body uses
  `subs="none"`, and restore the surrounding font after nested formatting.
  Enabled links and authored quotation marks in titles remain visible;
  Asciidoctor's roff title macro can discard them.
- Renders figure, table, example, and listing captions with their source-position
  label, number, custom prefix, or disabled-prefix behavior
- Renders images as readable alternative text and preserves configured image
  links with `.URL`
- Renders audio and video as titled static links, including every video source
  and poster, with one playback-fallback warning per document
- Omits markers for `[none]`, `[no-bullet]`, and `[unstyled]` lists, plus
  `[unnumbered]` ordered lists, and honors `%reversed` with optional `start`
- Gives `[horizontal]`, `[qanda]`, `[ordered]`, and `[unordered]` description
  lists distinct text layouts
- Shows bibliography labels and renders concealed index terms, nested terms,
  and `see` relationships in an `[index]` section, including before later
  sections. The catalog follows authored content and lists occurrences collected
  at that point; later body terms are excluded. Catalog generation is an acdc
  extension over Asciidoctor manpage output.
  An index in an AsciiDoc table cell shares earlier outer-document and cell terms with the containing document, including when the table is inside a compound block or list.
- Omits a section heading for `%notitle` while retaining its body and
  cross-reference text
- Omits automatic and macro tables of contents, matching Asciidoctor's manpage
  backend; section headings remain visible
- Renders cross-references as display text. Roff manpages do not provide
  in-document jump targets, so standalone anchors remain non-visible
- Honors `hide-uri-scheme` in visible URL, `link:`, and automatic-link text
  without changing the full link target
- Applies the same portable role presentation to inline spans and link labels:
  `underline` and `subtitle` use italics, and `big` and `small` use relative
  type sizes. Unattributed highlights and the `highlight` role use bold;
  ID-only and custom-role spans keep plain text.
- Preserves unsupported strikeout and overline meaning as `[deleted: ...]` and
  `[overlined: ...]`. Unknown and color roles retain their text without added
  formatting. These role fallbacks produce one structured warning per document.
- Renders explicit and automatic callouts as bold `(N)` labels in listing and
  literal blocks, styled or indented verbatim paragraphs, and explanation lists.
  Removes XML guards and the common prefixes `//`, `#`, `--`, and `;;`, regardless
  of source language or `icons`. The block's `line-comment` attribute selects a
  custom prefix; an empty value disables prefix removal. At most one ASCII
  space after a prefix is removed; other spaces and line breaks stay intact.
  Spaces within a custom prefix are required and removed with it, so
  `line-comment="// "` also matches when no extra separator follows.
- Maps table frames and grids to portable `tbl` borders and rules. Proportional
  and percentage column widths become minimum-width hints; automatic columns
  and `%autowidth` remain content-determined. Explicit table widths, left or
  centered placement, and top, middle, or bottom cell alignment are retained.

== Differences from Asciidoctor

The `acdc` manpage converter aims for compatibility with Asciidoctor's manpage backend, but some features may differ:

- With `subs="callouts"`, acdc recognizes source callout markers even without
  special-character substitution; Asciidoctor leaves them literal. Disabled
  callouts and markers inside raw passthroughs remain literal in both.
- Nested formatting restores its enclosing font. In `*Bold _italic_ tail*.`,
  `tail` is bold and the final period is roman; Asciidoctor can leave the period
  and following paragraphs italic. The same rule applies to roles, link
  labels, titles, list terms, tables and enabled code formatting. Inner styles
  replace the outer font while active; bold plus italic is not combined into a
  separate font. This is a converter correction, independent of SDR-5.
- Portable `tbl` has no row background fills or true floating tables. Row
  stripes render without shading, and floats or right alignment fall back to
  non-wrapping left alignment with structured warnings. Content can expand a
  table beyond requested minimum widths. Mandoc may center vertically aligned
  cell content because it ignores `tbl`'s top and bottom modifiers.
- Interactive audio and video playback is unavailable. The converter emits one
  structured warning and preserves the media as static links.
- Unlike Asciidoctor's manpage backend, which drops bibliography labels and
  index catalogs, acdc preserves both as portable roff text.
- Unlike Asciidoctor's manpage backend, which ignores `%notitle` and inline
  roles, acdc preserves their backend-neutral meaning with portable roff
  fallbacks.
- Custom macro extensions not supported

== Cross-reference labels

Manpages display reference labels without interdocument links. For
`xref:guide.adoc[]`, the converter looks up the local `guide` catalog entry.
Its reference label or title supplies the text; otherwise the output is
`[guide]`. Nonempty fragments remain part of the lookup key, as in `guide#part`;
a trailing `#` is ignored.
This matches Asciidoctor's manpage behavior. Local references such as
`<<guide.adoc>>` keep the complete ID, and explicit labels take precedence.
Labels follow the selected parser mode. In Draft mode, double-quoted `reftext`
values stay literal; use single quotes for formatted labels.

== Date selection

The printed manpage date comes from `docdate`, matching Asciidoctor. Use
`:docdate: 2026-01-01` or the CLI option `-a docdate=2026-01-01` to pin it.
`revdate` remains revision metadata and does not select the printed date.

The default date comes from `SOURCE_DATE_EPOCH`, the source file's modification
time, or the time the source is parsed. An empty `docdate` prints an empty date;
a header unset also removes the date comment. `:reproducible:` suppresses both
the printed date and its comment. Later body assignments do not change the date
selected from the document header.

Caller unsets follow acdc's attribute locking rules. The CLI option
`-a docdate!` removes the date and its comment, even if the header sets it.
Asciidoctor instead restores the default date for this caller unset.

== Convention warnings

The first-section check accepts literal `NAME` or the effective `manname-title`,
ignoring ASCII case. Empty or unset settings still accept `NAME`. Other headings
retain the convention warning. The second section is still checked for `SYNOPSIS`.

Authored section headings remain in the output. Asciidoctor can generate the name
heading from `manname-title` instead. These convention warnings describe acdc's
supported heading policy; they do not claim identical reference diagnostics.

== Testing

The rendered-font integration tests require `groff` and `mandoc` on `PATH`.
Install both packages on Linux; on macOS, install groff and use the system
mandoc. CI installs both. The tests check groff's font selections and mandoc's
terminal emphasis, in addition to the roff snapshots.

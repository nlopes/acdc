= `acdc-converters-manpage`

Manpage converter for `AsciiDoc` documents. Generates native roff/troff output suitable for the `man` command.

== Usage

[source,console]
....
acdc convert --backend manpage mycommand.adoc
....

This generates `mycommand.1` (or another extension based on the manual section) in the same directory as the source file.

== Output Format

Generates roff/troff format compatible with:

- GNU groff
- mandoc (OpenBSD)
- Traditional Unix nroff/troff

=== Roff Macros Used

- `.TH` - Title header with name, section, date, source, manual
- `.SH` - Section headings (NAME, SYNOPSIS, DESCRIPTION, etc.)
- `.SS` - Subsection headings
- `.PP` - Paragraph breaks
- `.IP`, `.TP` - Indented and tagged paragraphs for lists
- `.EX`/`.EE` - Example blocks (literal/listing content)
- `.TS`/`.TE` - Table start/end (tbl preprocessor)
- `\fB`, `\fI`, `\fP` - Bold, italic, previous font

== Viewing Output

View the generated manpage:

[source,console]
....
man ./mycommand.1
....

Or with groff directly:

[source,console]
....
groff -man -Tascii mycommand.1 | less
....

=== macOS and tables

macOS ships with `mandoc` which has limited support for the `tbl` preprocessor.
Manpages that contain tables will show a warning:

....
This manpage is not compatible with mandoc(1) and might display incorrectly.
....

To render tables correctly, install GNU groff and use the `-t` flag to enable `tbl` processing:

[source,console]
....
brew install groff
groff -t -man mycommand.1 -T utf8 | less
....

== Technical Details

The manpage converter:

- Escapes special roff characters (backslash, period at line start, apostrophe)
- Disables hyphenation (`.nh`) for consistent formatting
- Uses left-alignment only (`.ad l`) as is standard for manpages
- Includes the tbl preprocessor directive (`'\" t`) when tables are present
- Preserves inline formatting (bold, italic, monospace) using roff font escapes
- Renders figure, table, example, and listing captions with their source-position
  label, number, custom prefix, or disabled-prefix behavior
- Renders images as readable alternative text and preserves configured image
  links with `.URL`
- Renders audio and video as titled static links, including every video source
  and poster
- Omits markers for `[none]`, `[no-bullet]`, and `[unstyled]` lists, plus
  `[unnumbered]` ordered lists, and honors `%reversed` with optional `start`
- Gives `[horizontal]`, `[qanda]`, `[ordered]`, and `[unordered]` description
  lists distinct text layouts
- Shows bibliography labels and renders concealed index terms, nested terms,
  and `see` relationships in a final `[index]` section

== Differences from Asciidoctor

The `acdc` manpage converter aims for compatibility with Asciidoctor's manpage backend, but some features may differ:

- Some advanced table features not yet implemented
- Interactive audio and video playback is unavailable. The converter emits one
  structured warning and preserves the media as static links.
- Unlike Asciidoctor's manpage backend, which drops bibliography labels and
  index catalogs, acdc preserves both as portable roff text.
- Custom macro extensions not supported
